# Reasonix Token HUD · dsh-go

Reasonix Token HUD 的手机原生适配版：不依赖 Harness Web Client，直接在 dsh-go 的输入框上方显示一条实时状态。

- npm：`reasonix-token-hud-dshgo`
- GitHub：<https://github.com/beijiangwx/dsh-reasonix-token-hud/tree/main/dshgo>
- Cordis（网页 / 桌面）版仍是 `reasonix-token-hud`，两者互不干扰。

## 安装

```sh
dsh plugin --profile web add reasonix-token-hud-dshgo
```

装好后打开 App。`lib/` 里的代码改动要在 App 里重启内核才生效（插件详情页「重启内核以重载」，或 设置 › 本机引擎 › 重启）；`package.json` 的清单改动会自动重读。

从源码目录直接装也可以，`dsh plugin --profile web add <插件目录>`。

## 在哪看

- **输入框上方状态条**：`总¥0.04·本轮¥0.042·1h3m后峰`（24 字内；放不下依次省余额、时段，**总费用与本轮费用不会被省**）。
  - 末尾 `1h3m后峰` / `2h后谷` 是**距离下次调价还有多久**，和电脑版费用计量的提示同一个意思。
- **长按任意一条回复 → 「本轮费用」**：显示这条回复所属那一轮的费用与时段，并复制到剪贴板。每轮各查各的，不共用最后一轮。
- **长按任意一条回复 → 「钉住本轮」**：把那一轮固定在状态条上，显示成 `总¥0.04·第3轮¥0.16·25m后峰`，带轮次号，不会被误读成最新一轮。再长按同一条点一次就取消；长按另一条则改钉到那条。点击后立刻重绘，不用等下一次刷新。
  - 钉住只存在内存里、按会话分开：切换对话不会串，重启引擎后回到「跟着最新」。
  - 面板顶部会多一行说明当前是「跟着最新」还是「状态条已钉住」。
- **每轮脚注**（较新 App）：回答下方脚注追加本轮费用，如 `¥0.042·峰`、`¥0.0021·谷`（峰=峰时全价，谷=谷时半价）。
  - 注意：App 只在最长的那一种脚注写法里放插件尾注，而正常问答轮的脚注挤在回复的图标行里、放不下那一版，所以**正常问答轮看不到尾注**，只有出错 / 被停下 / 只有工具调用的轮（脚注独占一行）才看得到。这种情况以状态条和长按菜单为准。
- **点状态条**：打开「用量与费用」面板，含总费用旁的峰谷提示与倒计时（`谷时 · 1小时2分后进入峰时（09:00）`）、tokens、缓存命中、上下文占用、四类 token、**按回合费用表**、按模型费用、峰谷费用与缓存节省。
- **「复制用量」动作**：输入框操作菜单里，把本次会话摘要复制到剪贴板。
- 面板也会出现在对话详情的「插件」页签和「全部功能」里。

## 数据口径

- 费用为估算：输入 ¥2 / 缓存读取 ¥0.04 / 输出 ¥8（每百万 tokens），谷时按 50% 计。
- 峰时按官方定价：工作日 09:00–12:00、14:00–18:00（北京时间），其余时间、周末与法定节假日为谷时。节假日日历每年变，插件不内置；需要按节假日算谷时，给引擎设 `PEAK_HOLIDAYS='["2026-10-01","2026-10-02"]'`（北京时区的 `YYYY-MM-DD`）。
- 每轮费用与总费用同一口径（同一份样本、同一套峰谷价）；尾注与回合表按金额量级显示 2–4 位小数，与总额可能有末位差异。
- 费用低于 ¥0.0001 的回合显示 `<¥0.0001`，不会静默省略。
- 余额来自引擎的 `deepseekAccount.getBalance`；平台余额接口不可达时显示 `—`，不影响 token 与费用统计。
- 扫描当前会话事件，按 `turn:step` 替换、重试另计，与 token-meter 的 `tokenUsage` 口径一致；按样本时间区分峰谷。

## 开发

用 App 自带的插件检查器（路径见 dsh-go 的界面与技能设置）：

```sh
node "$DSH_HOME/skills/dsh-go-plugin/kit/bin/check.mjs" . --load
```

`lib/` 改动后需在 App 的「引擎」页重启引擎。
